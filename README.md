# 🚀 Plano de Estudos: Engenharia de Dados em 30 Dias

Bem-vindo ao seu repositório de estudos! Este espaço foi estruturado para materializar e acompanhar o seu plano de 30 dias focado em **projetos práticos e documentação de mercado** para Engenharia de Dados. 

O objetivo principal é construir um portfólio sólido utilizando as ferramentas mais demandadas no mercado atual.

---

## 🎯 Objetivo Geral

> **Dominar os fundamentos de Engenharia de Dados em 30 dias** por meio de prática direta, construindo um portfólio técnico focado em Python, SQL, AWS (S3), Google BigQuery, dbt e Apache Airflow.

---

## 📅 Visão Geral do Cronograma

O plano é dividido em 4 blocos semanais com foco incremental:

| Semana | Tema Principal | Ferramentas Chave | Foco da Prática |
| :---: | :--- | :--- | :--- |
| **1** | **Modelagem & Manipulação** | Python, Pandas, PySpark | Modelagem OLAP (Star Schema) e limpeza de dados local. |
| **2** | **Armazenamento em Nuvem** | AWS S3, Google BigQuery | Upload de dados, particionamento e consultas SQL analíticas. |
| **3** | **Pipelines & Transformação** | AWS Glue, dbt | Conceitos de ETL/ELT e transformações testadas no DW. |
| **4** | **Orquestração & Portfólio** | Apache Airflow | Automatizar o fluxo fim a fim e publicar o projeto no GitHub. |
